# Budget Manager CLI

A simple command-line budget manager built in Python.

## Features

- Add income
- Add expenses
- View all expenses
- View all income
- View total balance
- Input validation for numeric values
- Formatted currency output

## Updates

 - Add accumulation
 - Validation
 - Save-to-file

## How to Run

Make sure Python is installed.

Run:

python budget_manager_.py
